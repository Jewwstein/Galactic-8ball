# Soul Slime 3D Visual Prototype v0.4

This revision focuses on rendering, atmosphere, combat readability, and the feel of the 3D cave vertical slice.

# Soul Slime 3D Test v0.3

Third-person Android vertical-slice test built in Godot 4.7.2.

## Included gameplay
- Third-person controllable slime
- Touch joystick + drag camera
- Attack, dodge, absorb buttons
- Kenney modular cave visuals
- Quaternius slime and bat models
- Emissive collectible crystals
- Essence and Morph Data feedback
- First trait acquisition: Echo Sense
